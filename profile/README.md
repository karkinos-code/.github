<div align="center">
  <h1>Karkinos</h1>
  <p><em>Fast particle tracking for plasma-based accelerators, written in Rust.</em></p>
</div>

Karkinos (Καρκίνος) tracks charged particles through plasma wakefields quickly
enough for rapid design studies and, eventually, real-time beam tuning.
